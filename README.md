# or1n-rename-file-name-to-date-created

## Title

or1n Rename File Name To Date Created

## Short Description

A modern WinUI 3 desktop app to batch rename files in a selected folder to their original date created/taken, with customizable formatting, prefix/suffix, and smart options. Features a modern, accessible UI with advanced controls, animations, and logging.

## Features

- WinUI 3 modern controls and samples (AppWindow, compact sizing, styles, theme shadow, templates, RichEditBox, custom/user controls)
- Modern UI design: color, accent text, geometry with corner radius, iconography (FontIcon for light/dark theme)
- Title, short description, open-folder picker, scan button, progress/info box, results area
- Batch scan and rename files by date created/taken (supports images, videos, and more)
- Customizable filename formatting, prefix/suffix, smart numbering, and original filename options
- Accessibility: screen reader, keyboard, color contrast
- Basic inputs: Button, ComboBox, DropdownButton, ContentDialog
- Layouts: card, form, MenuBar, XamlUICommand
- Motion: animations, transitions, easing
- Tooltips, ProgressRing, InfoBar
- Styling: Acrylic, animated, compact, Backdrop with Mica, radial gradients, theme shadow
- NumberBox, TextBox, app theme (system/dark/light)
- Logging/debug info at the bottom

## Requirements

- Windows 11 (recommended)
- Visual Studio 2022 or later
- .NET 8.0 SDK or later
- WinUI 3 (Windows App SDK)

## Installation

1. Clone this repository
2. Open the solution in Visual Studio
3. Restore NuGet packages
4. Build and run the app

## Usage

1. Launch the app
2. Select a folder
3. Scan files
4. Choose rename options
5. Rename files

## Accessibility

- Full screen reader and keyboard support
- High color contrast
- Accessible controls and layouts
